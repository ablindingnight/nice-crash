# Launcher fonts (SIL Open Font License 1.1)

Bundled for the Nice Crash UI (design: NICE_CRASH_UI_DESIGN.md section 2). The launcher loads every .ttf here
(host/src/launcher/ui.cpp, a GDI+ private font collection); without them it falls back to Windows fonts.
