**Nice Crash v0.2 preview**: an unofficial native PC port of Excite Truck (Wii), built from the
[matching decompilation](https://github.com/ablindingnight/excite-truck).

**No game files are included.** You need your own Excite Truck disc (USA, REXE01) dumped from your Wii
(.iso, .rvz, .wbfs, .wia, .gcz, .ciso, a plain .nkit.iso, or a Dolphin-extracted folder).

### What's new since v0.1
- **The game comes ready-made.** No compiler or Python in the download and no build on your PC: the first run
  checks your disc and reads its files in about a minute. The download is 41 MB instead of 156 MB. The game reads
  its data tables from your own disc when it starts, so the download still holds no game data (every release is
  scanned for that before it goes up).
- **NKit images**: a plain `.nkit.iso` is read directly. If one can't be read, the launcher tells you how to
  convert it with Dolphin (right-click > Convert File > ISO or RVZ).
- **Custom soundtrack**: the game's SD-card MP3 player plays your own MP3s from `Music\Nice Crash` (an
  `EXCITE TRUCK` subfolder first, like the SD card; another folder can be set in Settings). Choose it in the game's
  Options > Track Music.
- **Smoother menus and HUD**: a live "Sharp" upscale (the default) and an AI texture step under *Enhance my game*.
- **Truck paint reflections** are smooth now (no blocky paint).
- **Sharpen videos** setting on the launcher's Graphics page.

### How to play
1. Download `NiceCrash-<date>-<commit>.zip` below and unzip it somewhere with a short path, e.g. `C:\Games\NiceCrash`.
2. Double-click **Start Nice Crash.cmd** (SmartScreen: *More info* > *Run anyway*).
3. Drag your disc image onto the launcher. It checks it's the retail USA disc and reads its files.
4. Press **PLAY**.

Coming from v0.1: unzip into a new folder. Your saves, settings and unpacked disc live outside it
(`%LOCALAPPDATA%\NiceCrash`, `%USERPROFILE%\Games\Nice Crash`), so they carry over; the old folder can be deleted.

Windows 10/11 64-bit, OpenGL 3.0 graphics, about 1 GB free. Keyboard: `2` accelerate, `1` brake, arrows/A-D steer,
Up turbo, Enter = HOME menu. Gamepads work too.

Still an early preview: expect rough edges. The launcher's **Logs > Save report** makes a folder you can share if
something breaks (nothing is sent anywhere). Not affiliated with or endorsed by Nintendo or Monster Games.
