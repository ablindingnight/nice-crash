@@@ drtex.cpp | ENDIAN: fn_802D78D4 reads the image's palette as words stored little-endian on disc (A, B, G, R in memory order) that the Wii's loader byte-swapped to R, G, B, A; the port does not run that swap, so the word is reversed here (else yellow/orange turn pink and alpha comes from red: the Excite Truck logo, the profile star's box). It then builds the RGB565 and IA8 palettes GX reads (TLUTs) with u16 CPU stores; GX reads big-endian, so on the PC each entry is stored byte-swapped
<<<
        c.word = pal[i];
        rgb[i] = To565(c.b);
        alpha[i] = c.b[3] << 8;
===
        c.word = __builtin_bswap32(pal[i]);
        rgb[i] = port_be16(To565(c.b));
        alpha[i] = port_be16(c.b[3] << 8);
